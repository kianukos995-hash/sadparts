# SadParts Prices

Рабочее место запчастей: прайсы поставщиков, поиск по артикулу, аналоги по OEM, клиенты со скидкой и сборка заказа. По духу близко к Автодилеру, но без лицензии TecDoc — кроссы живут в локальном каталоге и прайсах.

## Что внутри

- Поиск по артикулу / OEM / кроссу, группы аналогов
- Фильтры: цена, срок до Москвы, бренд, поставщик, наличие
- Поставщики: универсальный JSON и **Росско SOAP v2.1** (KEY1 + KEY2)
- Прайс Росско ZIP/CSV (~190 тыс. строк) на сервере, поиск по артикулу
- GetSearch / GetCheckoutDetails / GetCheckout / GetOrders / GetDeliveryDetails
- Клиенты: скидка и свои наценки по ценовым коридорам
- Каталог: закуп + цена клиенту, раскрываемые характеристики
- Номенклатура: все позиции прайса, фото, вес/габариты/материал, правка карточки
- Добавить прайс: просмотр, имя из файла, откат из истории
- Корзина черновиков и список собранных заказов, кнопка «Добавить из проценки»
- Редактирование названия позиции и привязка кросс-OEM
- Настройки → кнопка «Добавить ключ API»
- Telegram-бот по тому же каталогу
- PWA / окно Chrome (`npm run desktop`)

Каталог хранится в `data/store.json`, полный прайс Росско — в `data/catalogs/`.

## Росско

Первая версия API на `msk.rossko.ru` закрыта. Рабочий контур — `https://api.rossko.ru/service/v2.1` ([документация GetSearch](https://api.rossko.ru/index.php?path=/GetSearch&action=SOAP)).

1. В **Настройки** откройте Росско и вставьте **KEY1** и **KEY2** из кабинета.
2. «Проверить ключ» вызывает **GetCheckoutDetails** (доставка/оплата, адреса и реквизиты) и запоминает `delivery_id`.
3. Поиск в каталоге и в Telegram идёт в **GetSearch** (`text` + `delivery_id`, при курьере ещё `address_id`) и одновременно по загруженному прайсу. Ищите по артикулу, «бренд артикул» или GUID номенклатуры.
4. **Добавить прайс** принимает ZIP/CSV Росско и SOAP XML GetSearch: Номенклатура=guid, Бренд, Артикул=partnumber, Вендор-код (`артикул@vendor` для GetCheckout), цена, наличие, срок, склад=stock.id.
5. В заказе склад подтягивается через GetSearch, затем **GetCheckout**. Статусы — **GetOrders**. Волны курьера — **GetDeliveryDetails**.

Пока стоят демо-ключи, SOAP не дергает боевой Росско: поиск работает по файлу и демо-складу.

### Как окно программы

```bash
npm run build

```

Скрипт поднимает сервер (если он ещё не запущен) и открывает Chrome/Chromium в режиме `--app`. В браузере можно «Установить приложение» — это PWA.

## Цена клиенту

Ценовые коридоры задаются в **Настройки** (по умолчанию 0–300 / 300–550 / 550–1000 / 1000–2750 / 2750+). Наценка берётся из коридора закупа, затем скидка клиента:

`закуп + наценка категории − скидка клиента`

Наценка считается от закупа, скидка — от цены уже с наценкой. Пример: **1000 ₽**, коридор **16%**, скидка **8%** → `1000 + 160 − 92,80 = 1067,20 ₽`. Наценка **0%** остаётся нулевой и не подменяется значением «по умолчанию».

В карточке клиента можно перекрыть наценку каждого коридора. В каталоге, проценке и карточке позиции видна эта же формула в рублях. В заказе пустое поле наценки = коридоры; число перекрывает все позиции.

## Номенклатура

Характеристики зависят от типа детали (тормоза, фильтры, масла, подшипники, ремни, лампы, АКБ, щётки): вес, габариты, материал плюс узловые поля. **Номенклатура** — все строки прайса. В строке поиска подпункты: везде / артикул / OEM / название / бренд, затем все / в наличии / с фото. Остаток уменьшается в корзине и списывается при «Собрать заказ».

## Фото и шрифты

- Колонки «Фото», «Картинка», Image и гиперссылки Excel подхватываются автоматически.
- ZIP с картинками (`артикул.jpg` или путь из колонки) складывается в `data/media/` и отдаётся с `/api/media/…`. Клик по превью открывает фото в окне программы, не в новой вкладке.
- Текст прайса читается при любом шрифте ячейки Excel (Comic Sans, Calibri, кириллица, CJK). TTF из архива на сайт не ставятся — это имена шрифтов в файле, не веб-шрифты.
- Интерфейс использует Manrope + системный стек с эмодзи и запасными гарнитурами, чтобы артикулы с любыми символами не превращались в «квадратики».

## Проценка и прайсы

Каталог — общий вид. **Проценка** (`/quote`) — точечный поиск: клиент, бренд и поставщик с поиском по списку; срок сортируется стрелками от быстрых к долгим; доп. фильтры (поставщик, бренд, цена от/до и стрелки цены) открываются отдельной кнопкой. Прайсы до 800 тыс. строк лежат в `data/catalogs/*.jsonl` и не выгружаются целиком в браузер. Повторный импорт подсвечивает, у каких позиций изменились цена и остаток.

Черновики живут в **Корзине** (`/cart`): сюда падают позиции из проценки, у каждого клиента своя корзина. Собранные ЗК — список **Заказы**. Внутри заказа: добавить из проценки, удалить заказ, печать накладной с кнопкой «Назад». Номера: **ЗК-0001**, ЗК-0002…

## Накладная ЗК

Печатная форма как в файле «Заказ клиента ЗК-500»: шапка продавца, заказчик, авто, таблица позиций, итого, сумма прописью, подписи.

- В заказе: **Скачать Excel**, **Печать накладной**, **WhatsApp**, **В Telegram**. После печати есть «Назад» к заказу.
- Собранный заказ можно открыть кнопкой **Изменить** (количество, клиент, авто, комментарий) или вернуть в черновик
- Шаблон лежит в `templates/zakaz-klienta.xlsx`, реквизиты продавца — в Настройках

Telegram отправляет сам xlsx, если задан Chat ID клиента или общий Chat ID в настройках (появляется, когда человек напишет боту). WhatsApp открывает чат по телефону из карточки клиента — файл приложите из скачанного Excel.

## Добавить прайс

В **Поставщики** у каждой строки есть **Добавить прайс**: файл (CSV, ZIP, XLSX, XML) сразу пишется в каталог **этого** поставщика, а не в общий буфер. На карточке поставщика — зона перетаскивания; API-поставщики (включая Росско с KEY1/KEY2) тоже принимают файл.

Карта колонок из вкладки «Поля прайса» имеет приоритет: артикул, бренд, наименование, OEM, категория, цена, валюта, остаток, склад, кратность, срок. Остальные заголовки угадываются. KEY1/KEY2 и имя заголовка/параметра авторизации уходят в запрос API; для файла нужны колонки, не SOAP-ключи.

Страница **Добавить прайс** (`/import?supplierId=…`) тоже пишет в jsonl-каталог, а не в браузерный store. Кривой ZIP/CSV читается с пропусками. Новый прайс откатывается из истории.

```bash
npm run test:import
```

## Официальные каталоги замен

Встроен TecDoc-подобный локальный справочник кроссов (семь семейств OEM в демо). Боевые TecDoc / Laximo / ABCP / Exist catalog API подключаются как ещё один поставщик с ключом: прайс даёт цены и сроки, каталог — дерево аналогов. Лицензию TecDoc в репозиторий класть нельзя.
