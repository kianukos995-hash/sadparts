# SadParts Prices

Рабочее место запчастей: прайсы поставщиков, поиск по артикулу, аналоги по OEM, клиенты со скидкой и сборка заказа. По духу близко к Автодилеру, но без лицензии TecDoc — кроссы живут в локальном каталоге и прайсах.

## Вход

Скачивание из интерфейса убрано. Откройте сайт, войдите.

Иерархия: **Админ → Организация → Менеджеры организации → Клиенты → Гость**.

| Роль | Email | Пароль |
|------|-------|--------|
| Админ | admin@sadparts.local | Admin12345 |
| Организация | org@sadparts.local | Org12345 |
| Менеджер организации | manager@sadparts.local | Manager12345 |
| Клиент СТО | sto@sadparts.local | Client12345 |
| Клиент по ключу | ключ `SP-KEY-DEMO1` | без пароля, вкладка «Ключ» |
| Гость | кнопка «Войти как гость» | без скидки, рыночная наценка |

Организации заводит только администратор (меню «Организации»). Список редактируемый: скидка и наценка самой организации, потолок наценки и скидки для её клиентов. Ключ организации можно **забрать** — кабинет по паролю остаётся, но выдавать ключи и менять цены клиентов она больше не может, это делает админ. «Выдать ключ» возвращает контроль. Пример «Пример организации» специально **без клиентов**. Ключи клиентов: организация (пока ключ у неё) или админ.

На `/login` три вкладки: **Почта**, **Ключ**, **Гость**. Вход по ключу — именной: ранг, цены и скидка как на карточке ключа. Кнопка «Войти как гость» остаётся анонимом по устройству и с ключом не смешивается.

Демо-ключ для Preview и curl: **`SP-KEY-DEMO1`** (клиент Клюева Дарья, Kia Rio). Неверный ключ отвечает одной ошибкой, без списка существующих кодов.

Карточка ключа в **Ключи и регистрации** / кабинете организации: ФИО, телефон, email, для клиента и гостя ещё авто. Поля необязательны. Правка владельца синхронизируется с профилем. Админ видит все ключи, организация — свои, менеджер — только выданные им.

Клиент и гость видят только продажную цену по коридорам, без закупа, ключей API, денег, персонала, чужих клиентов и **имён поставщиков**. В проценке и корзине — срок поставки и наличие. Полный каталог скрыт: ищут по артикулу, названию или категории с **Главной**. Гостевая корзина привязана к cookie устройства и IP и лежит на сервере — закрытие вкладки её не стирает.

Проценка: клик — количество с учётом остатка; ноль на складе — «нет в наличии на этом складе — выберите другую позицию»; ПКМ — меню (в текущую корзину / кол-во / карточка), не новый заказ; крестик сбрасывает черновик; склады и сроки раскрываются стрелкой у цены.

Чтобы пускать людей с интернета на Windows 11: `start-windows.bat`, затем Cloudflare Tunnel или ngrok на порт 43217. На своём VPS — Docker, см. DEPLOY.md.

## Что внутри

- Поиск по артикулу / OEM / кроссу, группы аналогов
- Клиент и гость: **Главная** с категориями запчастей и проценкой; полный каталог скрыт; вместо поставщика виден срок поставки
- Фильтры: цена, срок, бренд, наличие; фильтр поставщика с логотипами — только рабочему столу
- Поставщики: каталог с логотипами (AD SMARTEC, ARMTEK, Авторусь, AUTO PULSE и другие), свой JSON API, файл с названием, прайс письмом
- Типы API: Bearer, заголовок, query, два ключа (логин/пароль), Росско SOAP KEY1+KEY2
- Прайс по почте: тема/адрес/имя файла распознают поставщика; .eml и вложения CSV/XLSX/ZIP
- Добавление поставщиков и прайсы — в **Настройках** (с обзора убраны, в меню группы «Прайсы» нет)
- Обзор: сколько поставщиков подключено и сколько нет
- Прайс Росско ZIP/CSV (~190 тыс. строк) на сервере, поиск по артикулу
- GetSearch / GetCheckoutDetails / GetCheckout / GetOrders / GetDeliveryDetails
- Клиенты: скидка и свои наценки по ценовым коридорам
- Каталог: закуп + цена клиенту, раскрываемые характеристики
- Номенклатура: все позиции прайса, фото, вес/габариты/материал, правка карточки
- Добавить прайс: просмотр, имя из файла, откат из истории
- Корзина черновиков и список собранных заказов, кнопка «Добавить из проценки»
- Редактирование названия позиции и привязка кросс-OEM
- Настройки → кнопка «Добавить ключ API»
- Telegram-бот по тому же каталогу
- PWA / окно Chrome (`npm run desktop`)

Каталог хранится в `data/store.json`, полный прайс Росско — в `data/catalogs/`.

## Росско

Первая версия API на `msk.rossko.ru` закрыта. Рабочий контур — `https://api.rossko.ru/service/v2.1` ([документация GetSearch](https://api.rossko.ru/index.php?path=/GetSearch&action=SOAP)).

1. В **Настройки** откройте Росско и вставьте **KEY1** и **KEY2** из кабинета.
2. «Проверить ключ» вызывает **GetCheckoutDetails** (доставка/оплата, адреса и реквизиты) и запоминает `delivery_id`.
3. Поиск в каталоге и в Telegram идёт в **GetSearch** (`text` + `delivery_id`, при курьере ещё `address_id`) и одновременно по загруженному прайсу. Ищите по артикулу, «бренд артикул» или GUID номенклатуры.
4. **Добавить прайс** принимает ZIP/CSV Росско и SOAP XML GetSearch: Номенклатура=guid, Бренд, Артикул=partnumber, Вендор-код (`артикул@vendor` для GetCheckout), цена, наличие, срок, склад=stock.id.
5. В заказе склад подтягивается через GetSearch, затем **GetCheckout**. Статусы — **GetOrders**. Волны курьера — **GetDeliveryDetails**.

Пока стоят демо-ключи, SOAP не дергает боевой Росско: поиск работает по файлу и демо-складу.

## Как добавить разные API

В **Настройки → Поставщики** выберите карточку из списка (логотип совпадает с названием) или **Свой API**.

| Тип | Что нужно | Куда писать |
|-----|-----------|-------------|
| Файл с названием | Имя поставщика + CSV/XLSX/ZIP | Настройки → Поставщики → «Файл с названием» или вкладка «Прайсы» |
| Письмо | Тема, plus-адрес или имя файла | Настройки → Прайсы → «Прайсы по почте». Ящик `prajsy@sadparts.ru`, алиас `prajsy+armtek@sadparts.ru` |
| Bearer JSON | URL + токен | Вкладка API, авторизация Bearer |
| Заголовок | URL + ключ + имя заголовка (`X-Api-Key` и т.п.) | Вкладка API |
| Ключ в URL | URL + имя параметра (`key`, `apikey`) | Вкладка API, query |
| Два ключа | URL + KEY1/логин + KEY2/пароль | ARMTEK, АвтоКонтинент, АГАНТ |
| Росско SOAP | KEY1 и KEY2 из кабинета | Коннектор «Росско SOAP v2.1», URL подставляется сам |

Ключ уходит только на указанный URL поставщика. Демо-ключи Росско/Автопитер/Exist можно заменить на боевые в карточке.

## Почта прайсов: `prajsy@sadparts.ru`

Это **закреплённый ящик проекта**. Его нельзя сменить из формы настроек — только через `.env`, если когда-нибудь понадобится другой адрес.

Поставщик шлёт прайс:

- на общий ящик `prajsy@sadparts.ru` — распознаём по теме письма и имени файла (`ARMTEK прайс.csv`);
- или на plus-алиас `prajsy+код@sadparts.ru` (`prajsy+armtek@sadparts.ru`) — сразу в карточку этого поставщика.

Алиас прописывается в карточке поставщика автоматически.

### Как ящик цепляется в сам проект

1. Заведите ящик `prajsy@sadparts.ru` у регистратора домена (Яндекс 360 / Timeweb / свой IMAP).
2. Скопируйте `.env.example` → `.env` рядом с проектом и заполните секреты. Перезапустите `npm start` или Docker — Next.js читает `.env` сам, Docker — через `docker-compose.yml`.
3. **Основной крюк — входящий webhook.** Почтовый провайдер (Cloudflare Email Routing, Mailgun Inbound Parse, свой forwarder) делает `POST` сырого письма на:

   `https://ваш-сайт/api/prices/email/inbound`

   Заголовок: `Authorization: Bearer PRICE_MAILBOX_SECRET`. Тело: RFC822, `multipart` с полем `file` / `body-mime`, либо JSON `{ "raw": "..." }`. Без секрета в `.env` точка закрыта (401).
4. **Запасной крюк — IMAP.** В `.env` задайте `PRICE_IMAP_HOST`, `PRICE_IMAP_USER`, `PRICE_IMAP_PASS` (для Яндекса обычно `imap.yandex.ru:993`). В Настройках → Прайсы появится «Забрать письма». Тот же разбор можно повесить на cron:

   `curl -X POST -H "Authorization: Bearer $PRICE_MAILBOX_SECRET" https://ваш-сайт/api/prices/email/fetch`
5. Пока DNS и ящик не заведены, в той же карточке можно перетащить `.eml` или CSV — разбор тот же.

Проверить, что точка жива: `GET /api/prices/email/inbound` отдаёт адрес ящика и флаги `secretConfigured` / `imapConfigured` / `hooked`.

```bash
cp .env.example .env
# вписать PRICE_MAILBOX_SECRET и IMAP
npm start
```

## Цена клиенту

Ценовые коридоры задаются в **Настройки** (по умолчанию 0–300 / 300–550 / 550–1000 / 1000–2750 / 2750+). Наценка берётся из коридора закупа, затем скидка клиента:

`закуп + наценка категории − скидка клиента`

Наценка считается от закупа, скидка — от цены уже с наценкой. Пример: **1000 ₽**, коридор **16%**, скидка **8%** → `1000 + 160 − 92,80 = 1067,20 ₽`. Наценка **0%** остаётся нулевой и не подменяется значением «по умолчанию».

В карточке клиента можно перекрыть наценку каждого коридора. В каталоге, проценке и карточке позиции видна эта же формула в рублях. В заказе пустое поле наценки = коридоры; число перекрывает все позиции.

## Номенклатура

Характеристики зависят от типа детали (тормоза, фильтры, масла, подшипники, ремни, лампы, АКБ, щётки): вес, габариты, материал плюс узловые поля. **Номенклатура** — все строки прайса. В строке поиска подпункты: везде / артикул / OEM / название / бренд, затем все / в наличии / с фото. Остаток уменьшается в корзине и списывается при «Собрать заказ».

## Фото и шрифты

- Колонки «Фото», «Картинка», Image и гиперссылки Excel подхватываются автоматически.
- ZIP с картинками (`артикул.jpg` или путь из колонки) складывается в `data/media/` и отдаётся с `/api/media/…`. Клик по превью открывает фото в окне программы, не в новой вкладке.
- Текст прайса читается при любом шрифте ячейки Excel (Comic Sans, Calibri, кириллица, CJK). TTF из архива на сайт не ставятся — это имена шрифтов в файле, не веб-шрифты.
- Интерфейс использует Manrope + системный стек с эмодзи и запасными гарнитурами, чтобы артикулы с любыми символами не превращались в «квадратики».

## Проценка и прайсы

Каталог — общий вид. **Проценка** (`/quote`) — точечный поиск: клиент, бренд и поставщик с поиском по списку; срок сортируется стрелками от быстрых к долгим; доп. фильтры (поставщик, бренд, цена от/до и стрелки цены) открываются отдельной кнопкой. Прайсы до 800 тыс. строк лежат в `data/catalogs/*.jsonl` и не выгружаются целиком в браузер. Повторный импорт подсвечивает, у каких позиций изменились цена и остаток.

Черновики живут в **Корзине** (`/cart`): сюда падают позиции из проценки, у каждого клиента своя корзина. Собранные ЗК — список **Заказы**. Внутри заказа: добавить из проценки, удалить заказ, печать накладной с кнопкой «Назад». Номера: **ЗК-0001**, ЗК-0002…

## Деньги

Раздел **Деньги** (`/money`): приход и расход с поиском контрагента из списка (клиенты, поставщики, сотрудники) или **без контрагента**. Можно записать свободный приход/расход компании, **инвентаризацию** кассы и **зарплату** сотруднику. Способ — наличные, карта или безнал. На вкладке **Счета поставщиков** заводят накладную и подкрепляют оплату.

Поставщики разделены: **через файлы** (`/suppliers/files`) — CSV/ZIP/jsonl, **через API** (`/suppliers/api`) — ключи и синхронизация.

## Накладная ЗК

Печатная форма как в файле «Заказ клиента ЗК-500»: шапка продавца, заказчик, авто, таблица позиций, итого, сумма прописью, подписи.

- В заказе: **Скачать Excel**, **Печать накладной**, **WhatsApp**, **В Telegram**. После печати есть «Назад» к заказу.
- Собранный заказ можно открыть кнопкой **Изменить** (количество, клиент, авто, комментарий) или вернуть в черновик
- Шаблон лежит в `templates/zakaz-klienta.xlsx`, реквизиты продавца — в Настройках

Telegram отправляет сам xlsx, если задан Chat ID клиента или общий Chat ID в настройках (появляется, когда человек напишет боту). WhatsApp открывает чат по телефону из карточки клиента — файл приложите из скачанного Excel.

## Добавить прайс

В **Поставщики** у каждой строки есть **Добавить прайс**: файл (CSV, ZIP, XLSX, XML) сразу пишется в каталог **этого** поставщика, а не в общий буфер. На карточке поставщика — зона перетаскивания; API-поставщики (включая Росско с KEY1/KEY2) тоже принимают файл.

Карта колонок из вкладки «Поля прайса» имеет приоритет: артикул, бренд, наименование, OEM, категория, цена, валюта, остаток, склад, кратность, срок. Остальные заголовки угадываются. KEY1/KEY2 и имя заголовка/параметра авторизации уходят в запрос API; для файла нужны колонки, не SOAP-ключи.

Страница **Добавить прайс** (`/import?supplierId=…`) тоже пишет в jsonl-каталог, а не в браузерный store. Кривой ZIP/CSV читается с пропусками. Новый прайс откатывается из истории.

```bash
npm run test:import
```

## Официальные каталоги замен

Встроен TecDoc-подобный локальный справочник кроссов (семь семейств OEM в демо). Боевые TecDoc / Laximo / ABCP / Exist catalog API подключаются как ещё один поставщик с ключом: прайс даёт цены и сроки, каталог — дерево аналогов. Лицензию TecDoc в репозиторий класть нельзя.
