# SadParts Prices

Каталог автозапчастей: ключи API поставщиков, несколько способов загрузки прайса и Telegram-бот, который отвечает ценами из того же склада.

## Что внутри

- Левое меню: обзор, каталог, поставщики, добавление прайса, Telegram
- Поставщики с Bearer / заголовком / query-ключом
- Прайс файлом (CSV, XLSX, JSON, XML/YML, несколько сразу)
- Прайс по ссылке, вставкой текста, синхронизацией API или одной позицией вручную
- Слияние с текущим прайсом или полная замена
- Telegram-бот: артикул / OEM → цены поставщиков

Каталог хранится на сервере в `data/store.json`, чтобы бот видел те же позиции, что и веб-интерфейс.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43217](http://127.0.0.1:43217).

## Telegram

1. В @BotFather создайте бота и скопируйте токен.
2. В SadParts Prices откройте **Telegram-бот**, вставьте токен, сохраните.
3. Пока сайт открыт, бот сам забирает сообщения.
4. Напишите боту артикул, OEM или `/search колодки`.

Для сервера с публичным URL можно повесить вебхук на `/api/telegram/webhook`.

## Свой поставщик

**Поставщики → Добавить**: URL, способ авторизации, ключ, JSON-путь к позициям. Затем **Добавить прайс** или кнопка синхронизации в карточке.
