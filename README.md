# АвтоПрайс

Каталог автозапчастей с ключами API поставщиков, синхронизацией прайс-листов и загрузкой CSV/Excel.

## Что умеет

- Хранит поставщиков и их API-ключи в браузере (localStorage)
- Забирает JSON-прайс через прокси: Bearer, заголовок `X-Api-Key` или query-параметр
- Сопоставляет поля ответа (`items`, `data.products`, русские заголовки)
- Подгружает прайс файлом CSV или XLSX с автоопределением колонок
- Сводит предложения в каталог и подсвечивает минимальную цену по OEM

В комплекте три демо-поставщика (Росско, Автопитер, Exist Wholesale) с разными форматами API и ключами.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43217](http://127.0.0.1:43217).

Сборка:

```bash
npm run build
npm start
```

## Как подключить своего поставщика

1. **Поставщики → Добавить**
2. Укажите URL прайса, способ авторизации и ключ
3. Задайте JSON-путь к массиву позиций, например `items` или `data.products`
4. На вкладке «Поля прайса» пропишите имена полей: артикул, бренд, цена, остаток
5. **Проверить ключ**, затем **Забрать прайс**

Ожидаемый элемент массива:

```json
{
  "sku": "W71275",
  "brand": "MANN-FILTER",
  "name": "Фильтр масляный",
  "oem": "06D115562",
  "category": "Фильтры",
  "price": 890,
  "currency": "RUB",
  "stock": 12,
  "warehouse": "МСК-1"
}
```

Если API нет — создайте поставщика с источником «Только файл» и загрузите CSV/XLSX на странице «Загрузка прайса». Пример файла: `public/samples/price-list-example.csv`.

## Демо-ключи

| Поставщик   | Ключ                     | Авторизация        |
|------------|---------------------------|--------------------|
| Росско     | `rk_live_demo_rossko_91f2` | заголовок X-Api-Key |
| Автопитер  | `ap_sandbox_7c4e21`        | Bearer             |
| Exist      | `ex-feed-demo-4401`        | query `key`        |

Эндпоинты: `/api/mock-suppliers/rossko`, `/autopiter`, `/exist`.

## Важно

Ключи и прайсы живут в браузере этого устройства. На сервере они не сохраняются. Для продакшена позже можно вынести хранение в базу.
