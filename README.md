# SadParts Prices

Рабочее место запчастей: прайсы поставщиков, поиск по артикулу, аналоги по OEM, клиенты со скидкой и сборка заказа. По духу близко к Автодилеру, но без лицензии TecDoc — кроссы живут в локальном каталоге и прайсах.

## Что внутри

- Поиск по артикулу / OEM / кроссу, группы аналогов
- Фильтры: цена, срок до Москвы, бренд, поставщик, наличие
- Поставщики: универсальный JSON и **Росско SOAP v2.1** (KEY1 + KEY2)
- Прайс Росско ZIP/CSV (~190 тыс. строк) на сервере, поиск по артикулу
- GetSearch / GetCheckoutDetails / GetCheckout / GetOrders / GetDeliveryDetails
- Клиенты: скидка и свои наценки по ценовым коридорам
- Каталог: закуп + цена клиенту, раскрываемые характеристики
- Номенклатура: карточки артикулов (GUID, вес, ТН ВЭД)
- Добавить прайс: просмотр, имя из файла, откат из истории
- Заказ: OEM, артикул, количество, срок, закуп, цена со скидкой
- Редактирование названия позиции и привязка кросс-OEM
- Настройки → кнопка «Добавить ключ API»
- Telegram-бот по тому же каталогу
- PWA / окно Chrome (`npm run desktop`)

Каталог хранится в `data/store.json`, полный прайс Росско — в `data/catalogs/`.

## Росско

Первая версия API на `msk.rossko.ru` закрыта. Рабочий контур — `https://api.rossko.ru/service/v2.1` ([документация GetSearch](https://api.rossko.ru/index.php?path=/GetSearch&action=SOAP)).

1. В **Настройки** откройте Росско и вставьте **KEY1** и **KEY2** из кабинета.
2. «Проверить ключ» вызывает **GetCheckoutDetails** (доставка/оплата, адреса и реквизиты) и запоминает `delivery_id`.
3. Поиск в каталоге и в Telegram идёт в **GetSearch** (`text` + `delivery_id`, при курьере ещё `address_id`) и одновременно по загруженному прайсу. Ищите по артикулу, «бренд артикул» или GUID номенклатуры.
4. **Добавить прайс** принимает ZIP/CSV Росско и SOAP XML GetSearch: Номенклатура=guid, Бренд, Артикул=partnumber, Вендор-код (`артикул@vendor` для GetCheckout), цена, наличие, срок, склад=stock.id.
5. В заказе склад подтягивается через GetSearch, затем **GetCheckout**. Статусы — **GetOrders**. Волны курьера — **GetDeliveryDetails**.

Пока стоят демо-ключи, SOAP не дергает боевой Росско: поиск работает по файлу и демо-складу.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43217](http://127.0.0.1:43217).

### Как окно программы

```bash
npm run build
npm run desktop
```

Скрипт поднимает сервер (если он ещё не запущен) и открывает Chrome/Chromium в режиме `--app`. В браузере можно «Установить приложение» — это PWA.

Полноценный Electron/Tauri имеет смысл, когда понадобится офлайн-пакет и автозапуск без Node. Сейчас десктоп = локальный сервер + отдельное окно.

## Цена клиенту

Ценовые коридоры задаются в **Настройки** (по умолчанию 0–300 / 300–550 / 550–1000 / 1000–2750 / 2750+). Наценка берётся из коридора закупа, затем скидка клиента:

`закуп × (1 + наценка коридора%) × (1 − скидка клиента%)`

В карточке клиента можно перекрыть наценку каждого коридора. В каталоге выберите клиента — увидите закуп и цену продажи. В заказе пустое поле наценки = коридоры; число перекрывает все позиции.

## Номенклатура

Характеристики (вес, применимость, ТН ВЭД, сертификаты) и **фото** живут на карточке артикула. В каталоге у каждой строки есть место под картинку; если в прайсе только URL страницы — показываем ссылку «открыть в интернете». Полный список — **Номенклатура**.

## Фото и шрифты

- Колонки «Фото», «Картинка», Image и гиперссылки Excel подхватываются автоматически.
- ZIP с картинками (`артикул.jpg` или путь из колонки) складывается в `data/media/` и отдаётся с `/api/media/…`.
- Текст прайса читается при любом шрифте ячейки Excel (Comic Sans, Calibri, кириллица, CJK). TTF из архива на сайт не ставятся — это имена шрифтов в файле, не веб-шрифты.
- Интерфейс использует Manrope + системный стек с эмодзи и запасными гарнитурами, чтобы артикулы с любыми символами не превращались в «квадратики».

## Проценка и прайсы

Каталог — общий вид. **Проценка** (`/quote`) — точечный поиск по поставщику, бренду, артикулу, цене, сроку и наличию. Прайсы до 800 тыс. строк лежат в `data/catalogs/*.jsonl` и не выгружаются целиком в браузер. Повторный импорт подсвечивает, у каких позиций изменились цена и остаток.

Черновики заказа пишутся на сервер и дублируются в браузере: обновление страницы и обрыв связи не обнуляют корзину. Кнопка «Новый заказ» и ПКМ по строке проценки открывают отдельный черновик.

## Добавить прайс

Файл сначала открывается на просмотр (первые строки, предупреждения). Имя прайса подставляется из имени файла и его можно поменять. Кривой ZIP/CSV (служебная шапка, кривые кавычки, windows-1251) читается с пропусками, а не падает. Вновь загруженный прайс откатывается из **истории изменений** на той же странице.

```bash
npm run test:import
```

## Официальные каталоги замен

Встроен TecDoc-подобный локальный справочник кроссов (семь семейств OEM в демо). Боевые TecDoc / Laximo / ABCP / Exist catalog API подключаются как ещё один поставщик с ключом: прайс даёт цены и сроки, каталог — дерево аналогов. Лицензию TecDoc в репозиторий класть нельзя.
