# Windows 11 — как скачать и запустить SadParts Prices

Это программа на Node.js, не один HTML-файл. На Windows 11 её нужно **скачать ZIP, распаковать и запустить** `start-windows.bat`. Адрес `http://127.0.0.1:43217` из превью Cursor — это облачная машина агента, **не ваш ПК**. Пока bat не запущен у вас, в обычном Chrome на Win11 этот адрес будет пустым или «сайт недоступен».

## 1. Поставьте Node.js

1. Откройте [https://nodejs.org](https://nodejs.org) → **LTS**, установщик **Windows 64-bit (.msi)**.
2. Галочка **Add to PATH**.
3. Закройте и заново откройте Проводник / терминал (чтобы подхватился PATH).
4. Проверка в PowerShell:

```powershell
node -v
npm -v
```

Нужен Node **20** или новее.

## 2. Скачайте ZIP

Файл: `sadparts-prices.zip` (папка «Загрузки»).

## 3. Распакуйте — обязательно

В Проводнике: правый клик по zip → **Извлечь всё…** → например `C:\SadParts`.

Не открывайте `start-windows.bat` прямо из архива (двойной клик по zip). Windows тогда работает с временной копией, и запуск ломается.

Лучше короткая папка латиницей: `C:\SadParts`, не Рабочий стол с длинным русским путём.

## 4. Запустите

Внутри распакованной папки дважды кликните **`start-windows.bat`**.

Первый раз: `npm install` и сборка — несколько минут. Потом сам откроет браузер на http://127.0.0.1:43217

Чёрное окно консоли **не закрывайте** — это и есть сервер.

## Если Windows ругается

| Что видите | Что сделать |
|------------|-------------|
| SmartScreen «неизвестное приложение» | Подробнее → Выполнить в любом случае |
| Брандмауэр | Разрешить доступ для Node.js.js / node |
| `node не является внутренней командой` | Node не в PATH: переустановите msi, перелогиньтесь |
| Порт занят | Закройте старое чёрное окно и запустите bat снова |
| Антивирус режет npm | Добавьте папку проекта в исключения |

PowerShell, если bat блокируют:

```powershell
Set-Location C:\SadParts
Set-ExecutionPolicy -Scope Process Bypass
.\start-windows.ps1
```

## Google Диск коллегам

Загрузите `sadparts-prices.zip` на Диск → доступ по ссылке. Коллега на Win11 делает те же шаги 1–4. Google Диск **не запускает** программу сам.
